# Historias de Usuario – Página Web Restaurante

## HU1: Ingresar a la página (Login)

**Descripción:**
El usuario necesita poder ingresar fácilmente a la página web para visualizar toda la información disponible del restaurante.

## HU2: Ver el menú

**Descripción:**
El usuario quiere acceder al menú del restaurante para conocer los platos ofrecidos, sus precios y opciones disponibles.

## HU3: Reservar una mesa

**Descripción:**
El usuario desea contar con una opción para reservar una mesa en línea, evitando desplazarse o llamar por teléfono.

## HU4: Ver la ubicación

**Descripción:**
El usuario requiere ver la dirección y ubicación en un mapa para saber cómo llegar al restaurante sin perderse.

## HU5: Contactar al restaurante

**Descripción:**
El usuario necesita una opción para ponerse en contacto con el restaurante y hacer preguntas o solicitar información rápidamente.
